# 🎵 오늘의 노래 (Today's Song)

매일 사람들이 추천하는 음악을 모아서 공유하는 동아리 기반 커뮤니티 플랫폼

## 📋 기능
- 🎤 오늘의 노래 추천 (1곡/1일)
- ❤️ 반응 남기기 (좋아요/공감/들었어요)
- 💬 댓글 기능
- 📅 아카이브 (지난 추천곡 검색)
- 📊 추천 통계 (장르 분포, 워드클라우드 등)

## 🚀 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```
